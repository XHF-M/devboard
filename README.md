# devboard · 开发台板

> 本地单文件的开发待办台板：一句话录入、随手暂存、置顶悬浮小窗，数据全在本机。

一个 `index.html` 就是全部界面与逻辑：不联网、不登录、不起服务。用 Chrome / Edge 双击打开即可，数据落在浏览器本机存储里，换机器靠「备份 / 恢复」搬。

## 它能干什么

| 面板 | 解决的问题 |
|---|---|
| **待办** | 一句话记下需求 / Bug / 备忘，自动拆出类型、截止日、时段、优先级、模块；看板与列表两种看法，按状态 / 优先级 / 时间三组筛选叠加 |
| **暂存板** | 手边那张草稿纸：`Alt+S` 随时唤出，文字和截图随手贴，输入即自动保存；粘贴新内容时上一段自动归档，片段可复制 / 固定 / 编辑 / 搜索 |
| **悬浮窗** | 360×360 常驻桌面，按「逾期 / 今天 / 其它」分组，行内勾选完成；没在用时整窗半透明并切成深色 HUD，鼠标划过立刻实心；点 ⇤ 可贴边收起，只留一条窄边当把手 |

待办条目支持备注图片附件：抽屉里 `Ctrl+V`、拖文件、点「＋ 图片」三条入口，点开大图可左右翻看（`←` `→`）、滚轮缩放、复制、另存为。

## 快速开始

1. **只要待办**：双击 `index.html`（建议 Chrome），直接在顶部输入框说话。
2. **要悬浮窗**：装 Python 3，双击 `mini-top.py`；或建一个指向 `pythonw.exe mini-top.py` 的快捷方式，双击无黑框。

> `mini-top.py` 里页面路径写死为 `file:///E:/code/me/todo/index.html#mini`。clone 到别的目录后改这一行，或用环境变量 `DEVBOARD_PAGE` 覆盖。

## 录入语法

自然语言（识别结果会实时显示在输入框下方，点 chip 上的 × 可取消某一项）：

| 识别项 | 支持的写法 |
|---|---|
| 类型 | `bug` / `缺陷` / `报错` / `崩溃` / `闪退` → Bug；`备忘` / `想法` / `记录` → 备忘；其余 → 需求 |
| 日期 | 今天 / 明天 / 后天 / 明早 / 明晚 / 三天后 / 周三 / 下周一 / 6月1日 / 6-1 / 2026-06-01 / 月底 |
| 时段 | 上午 / 下午 / 晚上（需与日期同时出现） |
| 优先级 | 句首「紧急 / 尽快 / 马上」→ P0；「重要 / 优先」→ P1；「不急 / 有空」→ P3 |

精确写法（优先级高于自然语言）：`!P0`~`!P3`、`#模块`、`@明天`

```
登录 401 未跳转 !P0 @明天 #认证
需求 看一下无障碍攻略能不能迁到社区 明天上午
```

## 快捷键

| 操作 | 键 |
|---|---|
| 暂存板开合 | `Alt+S`（面板头部点一下可改成别的组合） |
| 关闭抽屉 / 暂存板 / 大图 | `Esc` |
| 大图缩放 | 滚轮（以光标为锚点）、`+` `-` `0`、双击切 1:1 |
| 大图左右翻页 | `←` `→` |

## 数据存在哪

- **条目与暂存板片段**：`localStorage`（key 前缀 `devboard.`）
- **图片二进制**：IndexedDB，库名 `devboard-img`；localStorage 只留指针与元数据
- **配额**：暂存板 60 张 / 单条附件 9 张 / 全库附件 120 张，三本账分开算，到顶明确拒绝、不静默淘汰

⚠️ 图片与浏览器站点数据同生共死：清站点数据会连图一起清掉。**定期用顶部「备份」导出 JSON**（会问是否连图片一起打包）。
换机器：备份 → 拷 JSON → 新机器「恢复」。

## 目录

```
index.html     主面板 + 暂存板 + 悬浮窗，全部界面与逻辑（无构建步骤，改完刷新即生效）
mini-top.py    悬浮窗的系统层：置顶、半透明、贴边收起、单实例守护
PRD.md         产品需求文档（15 段，含验收标准、异常清单与风险登记）
icon.*         图标：icon.ico（多尺寸）/ icon.svg / 180 / 256 / 512
```

## 明确不做

- 不做图文混排：备注是纯文本，图片作为附件挂在下方，不内联在句子里
- 不做同步 / 账号 / 云：单人、本地，数据不出这台机器
- 不做图墙、不做富文本编辑器
- 悬浮窗依赖 Win32 API（`SetWindowPos` 等），仅 Windows 可用；待办主体本身任意平台浏览器都能开
